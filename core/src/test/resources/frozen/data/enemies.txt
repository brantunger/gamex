// Enemy balance: one block per kind, then what the kinds share and each kind's attack. Read once when the game
// starts; change a value, start the game again and it is there. Every key must be present.
// Distances are in map cells, times in seconds, angles in degrees, turn rates in degrees per second.
// The Warden's attack is in warden.txt; the difficulty multipliers are in difficulty.txt.
//
// Per kind:
//   health                     hit points
//   move_speed                 cells per second (for the Warden its walk; its run is in warden.txt)
//   rail_damage_scale          share of the Rail Lance's damage a slug does to it
//   hazard_damage              whether a shock grate under it hurts it
//   avoids_hazards             whether it routes and steps round shock grates; only the guard can, so true
//                              for any other kind stops the game at start-up
//   boss                       whether it has the boss health bar, the boss death sound and the sealed boss doors
//   death_burst_size           size of the explosion it leaves
//   death_sound_gain           volume of its death sound
//   death_noise_range          its death wakes enemies this near that have a line of sight to it
//   death_noise_muffled_range  its death wakes enemies this near through walls
// A kind's radius and height are not here. They are its collision cylinder and stay in code (Enemy.Kind), because
// the .obj models are sculpted to them: changing one would change what can be hit, not what is drawn. The Warden
// is the exception: its .glb model is drawn scaled to its height.
