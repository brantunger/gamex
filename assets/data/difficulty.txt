// What each difficulty multiplies. Read once when the game starts. Every key must be present.
// The three difficulties themselves (EASY, NORMAL, HARD) are fixed in code: saved games store those names.
// The menu's lines for EASY and HARD ("70% DAMAGE / +25% PICKUPS") are fixed text in code too, and do not follow
// a value changed here.
//   damage_taken  damage the player takes: from enemies, exploding canisters, their own blasts and shock grates
//   pickup        what health, armor, energy and ammunition pickups give, and the ammunition a stage entered
//                 from Select Stage starts with
//   enemy_speed   how fast enemies wind up, fire and recover, and how fast their bolts fly

easy.damage_taken: 0.7
easy.pickup: 1.25
easy.enemy_speed: 0.85

normal.damage_taken: 1.0
normal.pickup: 1.0
normal.enemy_speed: 1.0

hard.damage_taken: 1.4
hard.pickup: 0.8
