// Every line of text the menus and the HUD show. Read once when the game starts. Every key must be present.
// A value is drawn with the pixel font (data/pixel-font.txt), which draws lower case as capitals; a character
// the font lacks stops the game at start-up, as does a mistake in a placeholder.
//
// Placeholders are names in braces:
//   {key:action}        the name of the key bound to an action: pause, retry, move_forward, move_back,
//                       move_left, move_right, dash, jump, interact, weapon_1, weapon_2, weapon_3, quick_swap,
//                       weapon_next, weapon_prev, fire, alt_fire, minimap, menu_up, menu_down, menu_left,
//                       menu_right, menu_confirm, quit, menu_click
//   {rail.zoom_factor}  the value of that key in data/weapons.txt
//   any other name      a value the game fills in. Each line has its own fixed set, the ones it uses below: a
//                       line must keep every one of them and can take no others.
// A value loses the spaces at its ends, and braces cannot be written as plain text.
//
// What an option does never depends on its text: the menus tell their options apart by fixed ids in code.
