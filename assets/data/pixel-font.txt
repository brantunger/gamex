// The HUD's pixel font: one block per character, each three pixels wide and five tall.
//
// A block is a header line, the word glyph, one space and the character, followed by five rows of three cells,
// top row first. A cell is # for a lit pixel or . for an empty one, and every glyph needs at least one lit pixel.
// Blank lines and lines starting with // are skipped anywhere; there are no comments at the end of a line.
//
// The character is whatever single character follows "glyph ", so the signs this syntax uses are written plainly:
// "glyph :" is the colon, "glyph /" the slash, "glyph #" a hash and "glyph ." the full stop. A header never
// starts with //, so the slash glyph is not taken for a comment.
//
// A character is defined once. Lower-case letters have no glyphs of their own: text is drawn in capitals, so a
// lower-case header is rejected. Space has no glyph either; it and any character missing here draw as a gap.
// The size is fixed at 3 x 5 in PixelFont, which checks every block against it and fails the launch when a block
// breaks these rules, naming this file, the line and the glyph (a bad header line is quoted instead).
